Política de privacidad

Última actualización: 12 de octubre de 2026.

Esta aplicación es una herramienta interna. La usa únicamente su titular para gestionar su propio canal de YouTube, Herencia Sagrada. No la usan terceros.

Qué datos se usan

Con la autorización del titular, la aplicación accede a la API de YouTube Data y a la API de YouTube Analytics para: subir y programar vídeos, actualizar su título, descripción y miniatura, gestionar listas de reproducción, y leer estadísticas de los vídeos del canal (vistas, tiempo de visualización, retención, suscriptores).

Cómo se guardan

Los tokens de acceso se guardan solo en el equipo del titular. Las estadísticas se guardan en una base de datos privada del titular. No se venden, no se comparten con terceros y no se usan con fines publicitarios.

Datos de terceros

La aplicación no recoge datos de espectadores ni de otros usuarios de YouTube más allá de las cifras agregadas que YouTube ofrece al titular del canal.

Revocar el acceso

El acceso se puede revocar en cualquier momento desde myaccount.google.com/permissions.

El uso de la API de YouTube está sujeto a las Condiciones del servicio de YouTube y a la Política de privacidad de Google.
